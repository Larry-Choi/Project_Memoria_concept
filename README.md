# Memoria

아무것도 모르는 상태에서 태어나, 사람처럼 자라고, 잊고, 다시 배우는 시스템을 만드는 개인 연구 프로젝트.

목표는 똑똑한 AI가 아니라 **진짜 배울 수 있는 AI**다. 지금 AI는 한 번 크게 배우고 멈추지만, Memoria는 겪을수록 바뀐다.

## 핵심 아이디어

기능 부품을 조립하지 않는다. 뉴런과 시냅스가 자라는 바닥 하나와 몇 개의 규칙만 둔다.

- 새로운 것이 쌓이는 곳에 뉴런이 생기고, 안 쓰면 사라진다
- 순서대로 켜지면 연결이 강해진다 (여기서 예측이 생긴다)
- 경험은 먼저 금방 잊히는 기억에 쓰이고, 자는 동안 일부만 오래가는 기억으로 옮겨진다
- 몸을 유지하려는 욕구 하나가 있고, 좋고 나쁨은 거기서 느낀다
- 뉴런을 유지하는 데 에너지가 든다

호기심, 취향, 망각, 질문은 따로 만들지 않고 이 규칙들에서 창발해야 한다.

## 창발 사다리

1. 익숙한 것에 무뎌진다 (습관화)
2. 어릴 때 일은 잊고 구조는 남는다 (망각)
3. 기억하는 법을 배운다 (되뇌기)
4. 말이 무언가를 가리킨다는 것을 안다 (기호 접지)
5. "뭐야?"라고 묻는다
6. "왜?"라고 묻는다 — 여기까지 오면 절반
7. 배운 것을 처음 보는 상황에 쓴다

자세한 내용과 결정 기록은 [설계 지침](docs/design-guideline.md)을 참고.
