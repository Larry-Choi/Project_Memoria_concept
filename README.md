# Memoria

사람처럼 배우고, 잊고, 다시 배우는 시스템을 만드는 개인 연구 프로젝트.

Memoria의 목표는 사람보다 뛰어난 AGI가 아니라 사람을 모델링하는 것이다. 핵심 문제의식은 **온라인 가소성**, 즉 처음 보는 일을 적은 경험으로 배우고, 배운 것을 유지하며, 새 도메인에 응용하는 능력이다.

## 구성 요소

1. **눈**: 호기심, 탐구심
2. **뇌**: 기억의 생성·연결·망각, 정원사(수면 단계)
3. **직관**: 맥락에 따른 핀포인트 회상과 연결, 판단
4. **입**: 출력
5. **피드백 고리**: 입 → 세계 → 눈, 실수로부터 배움
6. **작업공간**: 경쟁과 방송, 주의의 병목
7. **자기 모델**: 내가 무엇을 알고 모르는지

자세한 내용은 [설계 지침](docs/design-guideline.md)을 참고.
